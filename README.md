## 👨‍💻 About Me

I've been passionate about computers and technology since I was a kid.

Today, as a **Computer Science student at the University of Turin**, I use personal and academic projects as a way to explore new technologies, challenge myself, and turn ideas — or everyday problems — into working software.

I like approaching development methodically: understanding the problem, evaluating the context, and taking the time to find a solution that is not only functional, but also **clean, efficient, and appropriate for its purpose**.

I enjoy working on projects that push me outside my comfort zone and give me the opportunity to understand new concepts by actually building something with them.

I'm constantly learning, experimenting, and looking for the next interesting problem to solve.

## 🍴 ChefMate

**Mobile recipe-sharing application**

ChefMate is a project created to explore modern application development while building a complete and interactive product.

Users can browse recipes, create their own content, manage ingredients, interact with recipes, and access personalized features through authentication.

The project helped me work on both application logic and user experience, with particular attention to usability, responsiveness, and the interaction between frontend and backend components.

**Technologies:**  
`Svelte` · `JavaScript` · `Node.js` · `Express` · `MongoDB` · `HTML` · `CSS`

🔗 [Visit ChefMate](https://alexandru-chindris.github.io/ChefMate/)

## 🛍️ Meglio

**Clothing e-commerce platform**

Meglio is an e-commerce application developed with Svelte to explore the architecture, structure, and user experience behind a modern online store.

The platform focuses on product browsing, responsive interfaces, and the organization of a modern shopping experience.

Working on Meglio gave me the opportunity to improve my understanding of frontend organization, reusable components, application structure, and the design decisions behind an e-commerce experience.

## 🎓 University Projects

A selection of academic projects developed during my Computer Science studies at the **University of Turin**, focused on applying theoretical concepts through practical implementation.

### 🧠 Algorithms & Data Structures

Implementation in C of fundamental algorithms and data structures, including a hybrid sorting algorithm, custom Hash Table, ternary Heap Priority Queue, and sparse Graph.

The project focused on algorithmic complexity, memory management, testing, and implementation choices.

**Technologies:** `C`

### ⚙️ Operating Systems

Concurrent cafeteria simulation focused on process management, synchronization, shared resources, and inter-process communication in a Linux environment.

**Technologies:** `C` · `Linux`

### 🅿️ Blinkin Park

Relational database project for parking management, covering domain analysis, data modelling, relational schema design, data population, and queries.
